# Theming

16 Bits Design uses CSS custom properties as its theme API. Components read semantic
tokens such as `--bits-primary` and `--bits-surface`, so a theme can be selected or
customized without rebuilding the library.

## Set up the theme

Import the stylesheet once at your application entry point:

```tsx
import '@16-bits-design/ui/styles.css';
```

The stylesheet includes the fonts, component styles, token defaults, and both built-in
themes. Ember is the default theme, so no variables or provider are required for it.

## Use a built-in theme

Apply `data-bits-theme` to an element that contains the components:

```tsx
<main data-bits-theme="ocean">
  <Button>Continue</Button>
</main>
```

For React applications, `ThemeProvider` is recommended when a theme contains dialogs
or toasts. It scopes the theme and supplies a correctly themed portal container:

```tsx
import { ThemeProvider } from '@16-bits-design/ui/theme';
import { Button } from '@16-bits-design/ui/button';

export function App() {
  return (
    <ThemeProvider theme="ocean">
      <Button>Continue</Button>
    </ThemeProvider>
  );
}
```

The built-in theme names are `ember` and `ocean`.

## Create a custom theme

Start with the semantic color tokens. Because Ember provides complete values at
`:root`, a custom theme may override only the tokens that differ. For a portable,
complete color theme, define every token in the color table below.

```css
.brand-theme {
  --bits-surface: #101025;
  --bits-panel: #18183a;
  --bits-raised: #202052;
  --bits-muted: #292963;
  --bits-line: #42428a;
  --bits-line-strong: #6868bd;

  --bits-ink: #101025;
  --bits-primary: #8f8fff;
  --bits-primary-soft: #c2c2ff;
  --bits-primary-shadow: #35357e;

  --bits-text: #f4f4ff;
  --bits-text-soft: #cccced;
  --bits-text-dim: #adadd2;
  --bits-text-muted: #9696bd;
  --bits-text-faint: #707095;

  --bits-amber: #ffc857;
  --bits-success: #52e6a0;
  --bits-danger: #f05d5e;
  --bits-danger-soft: #ff9b9c;
  --bits-danger-shadow: #7a1a2d;

  --bits-shadow: rgb(0 0 0 / 50%);
  --bits-backdrop: rgb(8 7 20 / 72%);
}
```

Then apply the class to the provider. A custom `theme` name is optional, but useful as
a stable selector or application state value:

```tsx
<ThemeProvider theme="brand" className="brand-theme">
  <App />
</ThemeProvider>
```

## Scope more than one theme

Themes are inherited through the DOM, which allows multiple independently themed
regions on one page:

```tsx
<ThemeProvider theme="ember">
  <Workspace />
</ThemeProvider>

<ThemeProvider theme="ocean">
  <PreviewPanel />
</ThemeProvider>
```

Avoid setting tokens directly on individual components. Put overrides on a theme
container so components, nested content, focus states, and portals share one coherent
token set.
